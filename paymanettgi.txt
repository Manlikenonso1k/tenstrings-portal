We are fixing the Student Portal payment page. Conceptually, this is very simple: The course fee is stored in the courses table. When an admin creates a new student in the Filament backend (/admin/students/create), the student should immediately owe that course fee.

The Task:

Find the Hook: Go to the Filament StudentResource. Open the "Create" page logic (likely CreateStudent.php or inside the Resource hooks).

Grab the Fee: Use the afterCreate hook. When the student is saved, grab their course_id. Query the courses table to get the total_fee for that exact course.

Create the Snapshot (Debt): Create a new record in the exact table that the student portal's /portal/payments-page reads from (e.g., PaymentAdvice, Fee, or Invoice).

Set student_id = the new student.

Set amount_owed = the total_fee you just grabbed from the course.

Set status = 'unpaid' or 'pending'.

No CSV Overwrites: If you see that this student is being created via a CSV import, abort this hook. CSVs carry their own financial data. Only run this if the student is created manually via the Filament form.

Code Example for the Hook:

PHP
protected function afterCreate(): void
{
    $student = $this->record;

    // Grab the course fee
    $course = \App\Models\Course::find($student->course_id);
    
    if ($course) {
        // Create the owing record so the portal shows a balance
        \App\Models\PaymentAdvice::create([
            'student_id' => $student->id,
            'amount' => $course->total_fee, // The snapshot of the price
            'status' => 'pending',
            'description' => $course->name . ' - Tuition Fee'
        ]);
    }
}
Note for Agent: Ensure the model names (PaymentAdvice, Course) match the actual database schema.
